# 照片消消乐

用**真人照片**当牌面的「羊了个羊」式三消游戏。
纯 DOM + 原生 JS，无第三方库、无美术/音频素材文件，手机和电脑浏览器都能玩。

---

## 一、怎么开始玩

**双击 `启动游戏.bat`**，会启动本地服务器并自动打开浏览器。

命令行窗口里会显示两个地址：

```
电脑上玩：  http://localhost:8100
手机上玩：  http://192.168.x.x:8100     ← 手机连同一个 WiFi 就能打开
```

---

## 二、玩法

1. 牌堆是多层堆叠的，**只有没被压住的牌才能点**（被压住的牌蒙着一层雾）
2. 点一下牌，它会飞到底部的**卡槽**（一般 7 格）
3. 卡槽里凑齐 **3 张相同的牌**自动消除
4. **卡槽放满还没消除 → 输**
5. **全部牌清空 → 过关**

### 5 个关卡，一关比一关难

| 关卡 | 牌数 | 卡槽 | 特点 |
|---|---|---|---|
| 第 1 关 | 48 | 7 格 | 入门，堆得浅 |
| 第 2 关 | 72 | 7 格 | |
| 第 3 关 | 96 | 7 格 | 多一层 |
| 第 4 关 | 120 | 7 格 | 5 层深堆叠 |
| 第 5 关 | **150** | **6 格** | 地狱：牌最多 + 卡槽最少 |

难度是**两个维度一起加**的：牌数变多（种类分布更散）+ 层数变深（一次能点的牌更少）+ 最后一关砍掉一格卡槽。

### 三个道具（每关各 1 次）

| 道具 | 作用 |
|---|---|
| ↶ 撤销 | 把最后放进卡槽的那张牌退回牌堆 |
| ⇄ 洗牌 | 重新随机分配牌堆里剩余牌的种类 |
| ⇱ 移出 | 把卡槽里的牌全部退回牌堆 |

### 关键设计：**保证有解**

牌面不是随便撒的，而是先生成一条「从上往下取牌」的合法顺序，
再按这条顺序每 3 张配同一种牌。所以**每一局都必定存在通关路径**——
不像原版羊了个羊第二关那样可能死局。

## 三、换照片

1. 把照片放进 `assets\raw\`
2. 双击 `换照片.bat`（或 `python tools\make_cards.py`）

脚本会：
- 用 OpenCV 人脸检测找到每张照片的脸
- 以脸为中心裁成正方形（脸占牌面主体，上方留 40%）
- 缩放到 256×256，输出到 `assets\cards\card_1.png ... card_N.png`
- 同时生成 `cards.js`（页面读它，所以 file:// 也能用）
- 生成 `tools\cards_preview.png` 拼贴预览，**打开看看每张脸有没有居中**

**照片数量 = 牌的种数**。建议 8～12 种：
- 太少（比如 5 种）→ 太容易凑齐，不好玩
- 太多（比如 20 种）→ 凑不齐，太难

想加照片直接丢进 `assets\raw\` 重跑脚本即可，**不用改代码**。

## 四、调难度

打开 `js/game.js`：

```js
const CFG = {
  slotCount: 7,      // 卡槽格数 —— 调小更难（试 6），调大更简单
  fillRatio: 0.94,   // 牌堆占屏幕的比例
};
```

关卡定义在下面的 `LEVELS`：

```js
const LEVELS = [
  { layers: [{ c: 5, r: 6 }, { c: 4, r: 3 }, { c: 2, r: 3 }] },                                  // 48 张
  { layers: [{ c: 5, r: 8 }, { c: 4, r: 6 }, { c: 2, r: 4 }] },                                  // 72 张
  { layers: [{ c: 6, r: 8 }, { c: 5, r: 6 }, { c: 3, r: 4 }, { c: 2, r: 3 }] },                  // 96 张
  { layers: [{ c: 6, r: 9 }, { c: 5, r: 6 }, { c: 4, r: 4 }, { c: 3, r: 4 }, { c: 2, r: 4 }] },  // 120 张
  { layers: [{ c: 6, r: 9 }, { c: 5, r: 8 }, { c: 4, r: 7 }, { c: 3, r: 6 }, { c: 2, r: 5 }], slots: 6 }, // 150 张
];
```

- `c` / `r` = 这一层的列数和行数，牌数 = `c × r`
- 层与层之间会自动错开半格，形成堆叠遮挡（这是难度的主要来源）
- 每层比上一层小一点，就形成金字塔式的牌堆；**层数越多越难**
- `slots` 可选，用来覆盖卡槽格数（不写就是 7）
- **总牌数必须是 3 的倍数**（脚本按每 3 张一组分配）
- 想加关卡就往数组后面继续加，游戏会自动识别关数

## 六、调试参数

在网址后面加参数，方便截图和排查：

| 参数 | 作用 |
|---|---|
| `?level=2` | 直接进第 2 关（跳过开始界面） |
| `?level=1&auto=20` | 自动试玩 20 步（用简单策略） |
| `?level=1&solve=1` | 按预设解法自动通关（验证可解性） |
| `?level=1&auto=14&tools=1` | 自动试玩并顺便把三个道具都点一遍 |

例：`http://localhost:8100/?level=1&solve=1`
